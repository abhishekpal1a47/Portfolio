# Abhishek Pal — Portfolio Website

## Files
- `index.html` — main website
- `styles.css` — design
- `script.js` — mobile menu + reveal animations
- `resume.pdf` — your 2026 resume
- `assets/favicon.svg` — favicon

## Free deployment
Recommended: GitHub Pages.

1. Create a GitHub account if you don't have one.
2. Create a new public repository, e.g. `abhishekpal-portfolio`.
3. Upload all files/folders from this package.
4. Go to Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.
7. GitHub will give you a free `https://YOURUSERNAME.github.io/abhishekpal-portfolio/` address.

## Easy updates
- Replace `resume.pdf` when you have a newer resume.
- Replace the typography project panels later with approved project images if you get them.
- To change text, edit `index.html`.
- To change colors/design, edit `styles.css`.
